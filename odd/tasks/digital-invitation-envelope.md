# Feature: Digital Wedding Invitation with Envelope Opening Sequence

- **Objective**: Build a minimalist, elegant single-page digital wedding invitation web app featuring a gatefold envelope opening animation (ribbon untying, dual side flaps opening, card emergence), followed by the invitation card display and a video modal player.
- **Scope**:
  - Vite + React + TypeScript + Tailwind CSS + Framer Motion setup.
  - Interactive gatefold envelope component with ribbon/bow animation.
  - Main invitation card with luxury stationery aesthetics (serif typography, delicate borders, botanical motifs).
  - Video modal dialog with responsive embed player and light dismiss.
  - Configuration module for easy customization of text, dates, and video source.
- **Constraints**:
  - Mobile-first responsive layout.
  - Clean component separation and TypeScript types.
  - Smooth 60fps animations via Framer Motion.
  - English codebase / Spanish user-facing text as requested.
